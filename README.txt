Анализ риска сердечных заболеваний методами машинного обучения

Учебный проект по дисциплине «Технологии и инструментарий машинного обучения».

РТУ МИРЭА, кафедра прикладной математики.  
Студент группы ИНБО-22-24: Полещук А.А.

Описание проекта

Цель проекта — разработать систему анализа медицинских обследований с помощью методов машинного обучения. Модель решает задачу бинарной классификации наличия сердечно-сосудистого заболевания.

Практическая работа № 3

Выполнена подготовка данных, обучение и сравнение логистической регрессии, KNN, дерева решений, случайного леса и градиентного бустинга.

Исходный набор содержит 138 записей. Для разработки использовано 82 записи, из которых 65 выделены для обучения и 17 — для последующего тестирования.

По результатам пятикратной кросс-валидации выбран случайный лес:

- ROC-AUC — 0,800.
- Recall — 0,771.
- Precision — 0,735.
- F1 — 0,730.

Запуск проекта

Для установки необходимых библиотек:

`python -m pip install -r requirements.txt`

Для обучения моделей:

`python train.py --base base.csv`

Результаты обучения сохраняются в папке results_pr3. Итоговая модель находится в файле model_v1.joblib.

Файлы проекта

- features.py — проверка данных и подготовка признаков.
- train.py — обучение и сравнение моделей.
- prepare.py — применение сохраненной модели.
- restore_base.py — восстановление исходной выборки.
- requirements.txt — список используемых библиотек.
