ПРАКТИЧЕСКАЯ РАБОТА № 3 — выполненные эксперименты
Тема: анализ риска сердечных заболеваний методами машинного обучения.

Содержимое:
- base.csv: 82 записи, восстановленные из предоставленного Excel тем же стратифицированным разбиением (train_size=0.6, seed=42), что описано в ПР2. Контрольные статистики совпали; исходный base.csv ПР2 не предоставлен для побайтовой сверки.
- train.py, features.py, prepare.py: обучение, предобработка, применение модели.
- restore_base.py: восстановление base.csv из исходного Excel.
- results_pr3/: 27 экспериментальных вариантов (включая базовое решение), подбор параметров, графики, коэффициенты, train.csv (65), test.csv (17), обученный model_v1.joblib и описание model_v1.json.
- report.py, report_template.docx: генерация отчета по выполненным экспериментам.

Воспроизведение (Python 3.11+; проверено на Python 3.13.5, sklearn 1.8.0):
  python -m pip install -r requirements.txt
  python train.py --base base.csv
  python report.py

Применение сохраненной модели к новой порции (не для выбора модели):
  python prepare.py batch_01.csv --model results_pr3/model_v1.joblib
  Выход: prepared/features.csv, predictions.csv, quarantine.csv.

Итог: Random Forest, 200 деревьев, max_depth=2, min_samples_leaf=1; средний ROC-AUC CV=0.800. Отложенный тест и 4 новые порции не использовались для обучения или оценки при выборе модели.
